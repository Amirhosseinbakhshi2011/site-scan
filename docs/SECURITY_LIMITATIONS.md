# محدودیت‌ها و مرزهای امنیتی Aegis Sentinel AI

## دامنه مجاز اسکن

- فقط دامنه‌هایی که مالکیت آن‌ها از طریق DNS TXT یا فایل well-known تأیید شده باشد.
- هیچ URL دلخواه یا دامنه شخص ثالث بدون تأیید قابل اسکن نیست (محافظت در برابر SSRF و سوءاستفاده).

## آنچه اسکنر انجام می‌دهد

- درخواست‌های HTTP/HTTPS کنترل‌شده و با محدودیت نرخ
- بررسی هدرها، گواهی SSL، رکوردهای DNS عمومی
- پروب مسیرهای عمومی و شناخته‌شده (لیست سفید)
- تست‌های بی‌ضرر برای CORS و شاخص‌های ریدایرکت باز

## آنچه اسکنر هرگز انجام نمی‌دهد

- ارسال payload مخرب یا اکسپلویت
- brute-force رمز عبور یا توکن
- تست Denial-of-Service
- تغییر داده روی سایت هدف
- دور زدن احراز هویت
- دانلود یا ذخیره محتوای خصوصی کاربران
- اسکن پورت‌های خارج از محدوده صریح و مجاز
- ذخیره رمز عبور، کوکی نشست یا توکن احراز هویت سایت هدف

## سطح اطمینان یافته‌ها

- یافته‌ها با سطح confidence مشخص می‌شوند.
- بسیاری از یافته‌ها «شاخص» هستند نه exploitation تأییدشده.
- همیشه قبل از اقدام اصلاحی، یافته را به‌صورت دستی بررسی کنید.

## مسئولیت کاربر

استفاده از این نرم‌افزار فقط برای دارایی‌هایی مجاز است که شما مالک آن‌ها هستید یا مجوز کتبی ارزیابی امنیتی دارید. استفاده غیرمجاز ممکن است خلاف قوانین باشد.
